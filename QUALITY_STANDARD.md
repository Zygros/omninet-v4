# Repository Quality Standard

OmniNet distinguishes mathematical models, implementation, benchmarks, and claims. Canonical status labels: **Implemented**, **Prototype**, **Designed**, **Historical**, **Verified**, and **Unverified**.

Quantitative claims must link to reproducible benchmark inputs, methodology, outputs, and analysis. Security claims require appropriate cryptographic review; a functional encryption demo must not be represented as production cryptography without validation. Production readiness requires reproducible tests and operational controls.
